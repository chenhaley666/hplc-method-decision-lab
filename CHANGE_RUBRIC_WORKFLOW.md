# FC1 terminal hand-off consistency

At an evidenced, signature-bound Selectivity exhaustion declaration, the active
FC1 decision identifies Efficiency as the next parameter family, not a measured
successful method or a new injection recipe. The Retention reference, Selectivity
path, main conditions summary, expanded conditions, Efficiency section and print
report now consistently explain this boundary. FC1 panels do not apply the FC2
floor or request missing numerical N inputs. Changed specifications still expire
the declaration; a pressure failure takes precedence. Run records are unchanged.

Regression uses GR37 only in isolated test sessions. A constructed exhaustion
declaration exercises the terminal branch; it does not claim that GR37 completed
unperformed solvent, temperature or ligand experiments. The public default stays
blank. A novice/independent-user check is a usability validation, not a separate
mandatory submission artifact stated in the supplied teacher announcement.
